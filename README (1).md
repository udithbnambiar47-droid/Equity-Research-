# TCS Equity Research

Equity research and financial analysis of **Tata Consultancy Services (TCS)** — India's largest IT services company, listed on NSE (`TCS`) and BSE (`532540`).

## 📌 Overview

This repository contains a fundamental and quantitative research project on TCS as part of a broader look at the Indian IT services sector. It covers financial statement analysis, valuation, peer comparison, and a final investment thesis.

## 🎯 Objectives

- Analyze TCS's historical financial performance (revenue, margins, profitability)
- Evaluate key valuation metrics (P/E, EV/EBITDA, P/B, DCF)
- Benchmark TCS against Indian IT peers (Infosys, Wipro, HCLTech, Tech Mahindra)
- Assess industry tailwinds/headwinds (deal wins, attrition, currency, AI disruption)
- Arrive at a data-backed investment recommendation (Buy / Hold / Sell)

## 📁 Project Structure

```
tcs-equity-research/
├── data/                   # Raw and cleaned financial data (annual reports, screener exports)
├── notebooks/              # Jupyter notebooks for analysis & modeling
├── models/                 # DCF and valuation models (Excel/Python)
├── reports/                # Final research report, PDF/slides
├── charts/                 # Exported visualizations
├── src/                    # Reusable scripts (data pull, ratio calculations, plotting)
├── requirements.txt        # Python dependencies
└── README.md
```

## 🧮 Key Areas of Analysis

| Section | Description |
|---|---|
| Business Overview | Segments, geography mix, client concentration |
| Financial Analysis | Revenue growth, EBIT/EBITDA margins, ROE/ROCE, cash flows |
| Valuation | Comparable company analysis, DCF, historical valuation bands |
| Peer Comparison | TCS vs Infosys, Wipro, HCLTech, Tech Mahindra |
| Risk Factors | Currency exposure, attrition, discretionary spend cuts, AI-led disruption |
| Investment Thesis | Final rating with target price and time horizon |

## 🛠️ Tools & Tech Stack

- **Python** (pandas, numpy, matplotlib/plotly) for data analysis and modeling
- **Excel** for DCF and comparable company models
- **Jupyter Notebook** for exploratory analysis
- Data sources: Company annual reports/investor presentations, NSE/BSE filings, Screener.in, Moneycontrol

## 🚀 Getting Started

```bash
git clone https://github.com/<your-username>/tcs-equity-research.git
cd tcs-equity-research
pip install -r requirements.txt
```

Open the notebooks in `notebooks/` to reproduce the analysis, or view the final write-up in `reports/`.
